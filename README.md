# Fit4Life Gym Center — Demo Website

A responsive static website concept for Fit4Life Gym Center, Nanjarayapatna.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `fit4life-gym-website`.
2. Upload `index.html` to the repository root (the top level, not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish. The site URL should look like:
   `https://YOUR-USERNAME.github.io/fit4life-gym-website/`
7. Open the URL on your phone and test every button.

## Before handing it to the gym

- Confirm the exact address and Google Maps pin.
- Confirm opening hours and current prices/offer terms.
- Ask permission before using gym photos, trainer photos or logos.
- Replace illustrative stock photos with approved photos where possible.
- Check the WhatsApp number and Instagram link.
- Add the final live URL to Google Search Console after the owner approves the website.
- For a custom domain, purchase/register it only after the owner agrees who will own and renew it.
